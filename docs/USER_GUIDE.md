## نصب و راه‌اندازی {#نصب}

### دانلود

[دانلود PZ Launcher v2.1.0](https://github.com/yourusername/pz-luncher/releases/v2.1.0)

- **Windows**: `pz-launcher-2.1.0-windows.exe`
- **Linux**: `pz-launcher-2.1.0-linux.zip`
- **macOS**: `pz-launcher-2.1.0-macos.dmg`

### اجرا

اپلیکیشن را دانلود و اجرا کن. بار اول باید مسیر نصب بازی رو مشخص کنی.

### تنظیمات اولیه

**Settings → General:**
- **مسیر نصب بازی**: محل نصب Project Zomboid (مثلاً `C:\Games\ProjectZomboid`)
- **Backend URL**: `http://localhost:8080` (برای تست محلی)
- **مسیر Cache**: جایی برای ذخیره موقت (پیش‌فرض: `~/.pz-launcher/cache`)

> نکته: اگه بازی نصب نشده، لانچر هنگام اتصال به سرور خودش نسخه مناسب رو دانلود می‌کنه.

## اتصال به سرور {#سرور}

### 1. مرور سرورها

**Servers** تب میں لیست سرورها رو ببین.

هر سرور نشون می‌ده:
- **نام و توضیحات**
- **مقدار بازیکن فعال**
- **تعداد مود‌ها**
- **وضعیت**: ✅ آماده / 🟡 دارم دانلود می‌کنم / ⏳ منتظر

### 2. انتخاب سرور و Join

دکمه **Join** رو کلیک کن.

سپس Launcher:
1. **نسخه بازی رو چک می‌کنه** — آیا روی PC موجود است؟
2. **مود‌های لازم رو دانلود می‌کنه** — فقط موارد جدید
3. **پروفایل ایزوله می‌سازه** — هر سرور جداست
4. **آماده می‌کنه** — همه چیز جای خود

### 3. لانچ بازی

وقتی **Ready** ✅ شد، دکمه **Launch** فعال میشه.

بازی با مود‌های دقیق آن سرور اجرا میشه. بدون نگرانی از مود‌های سرور دیگر.

### 4. سوئیچ سرورها

بدون مشکل میتونی بین سرورها رفت و آمد کنی. هر سرور داره نسخه و مود‌های خودش.

## مدیریت نسخه‌های بازی {#نسخه‌ها}

### چند نسخه روی یک PC

Launcher می‌تونه چند نسخه بازی رو کنار هم نگه‌داره.

**مثال:**
- سرور Survival ← v42.16
- سرور RP ← v42.20
- سرور Build ← v42.16

هر سرور نسخه‌اش رو استفاده می‌کنه.

### Source Selection (اختیاری)

اگه نسخه موجود نباشه، Launcher منبع دانلود رو نشون میده:

```
دانلود v42.16

● Registry (PZ Launcher)    ✅ بهترین
  تأیید‌شده، سریع
  
● Agent (server.example.com) ✅ خوب
  مستقیم از سرور
  
● Hoster Upload             ⚠️ تأیید نشده
  صرفاً برای تست
```

**بهترین انتخاب**: Registry (اول)

## مدیریت فضای ذخیره‌سازی {#فضا}

### Storage → مشاهده فضا

**خلاصه:**
```
کل: 12.4 GB
├─ نسخه‌های بازی: 6.4 GB
└─ مود‌ها: 6.0 GB
```

### حذف نسخه‌های قدیمی

Launcher خودش تجویز می‌کنه چی حذف کنی:

```
v42.16 — 3.2 GB | 45 روز بدون استفاده
└─ استفاده در: (هیچ سرور فعال نیست)
[حذف]
```

**قانون‌های حذف:**
- نسخه‌هایی که 30+ روز استفاده نشده ✅
- اگه هیچ سرور فعالش استفاده نکنه ✅
- اگه هنوز یک سرور ازش استفاده کنه ❌ (بلاک شده)

### مود‌های بلااستفاده

مود‌های 60+ روز بدون استفاده و بدون سرور فعال پیشنهاد حذف می‌شن.

> نکته: مود‌های shared هستند. اگه دو سرور یک مود دارن، فقط یکبار ذخیره میشه.

## کمک به جامعه {#کمک}

### چرا کمک بدیم؟

هرچه بیشتر نسخه‌ها Verified بشن، سریع‌تر دانلود‌ها، کمتر مشکل.

### نسخه‌های جدید

**Contribute → دانلود جدید رو ارسال کن**

1. لانچر نسخه‌های روی PCت رو فهرست می‌کنه
2. دکمه **ارسال** کلیک کن
3. Hash محاسبه میشه (۲-۳ دقیقه، بسته به سرعت)
4. منتقل میشه به پایگاه داده جهانی

**وضعیت‌های trust:**
```
⏳ منتظر (۲/۳)  — یک نفر دیگه باید تأیید کنه
✅ تأیید‌شده   — ۳ نفر مستقل hash یکسون داشتن
```

> سازوکار: اگه ۳ نفر متفاوت (IP متفاوت) یک hash برای v42.16 ارسال کنن، کاملاً Verified می‌شه. هیچ ریسک نیست.

### مود‌های جدید

مود‌ها خودکار ارسال میشن — توسط سرور (Agent) که آن‌ها داره.

تو کاری ندارید کنید. 🎉

## عیب‌یابی {#عیب}

### مشکل: "Cannot connect to backend"

**دلیل:** سرور Backend آنلاین نیست

**راهنمایی:**
1. Settings → Backend URL رو چک کن
2. `http://localhost:8080/api/v1/health` رو در مرورگر امتحان کن
3. اگه کار نمی‌کنه، Backend نصب نشده. اینجا بخون: [Deployment Guide](DEPLOYMENT_REGISTRY.md)

### مشکل: "Server requires v42.16, you have v42.20"

**دلیل:** نسخه‌ات با سرور مطابقت نداره

**راهنمایی:**
1. Launcher خودش v42.16 رو دانلود می‌کنه
2. صبر کن تا دانلود تموم شه (۵-۱۰ دقیقه بسته به اینترنت)
3. بعد Join کن

### مشکل: "Mods failed to download"

**دلیل:** شبکه قطع شد یا مود حذف شد

**راهنمایی:**
1. اینترنت رو چک کن
2. دوباره Join کن — Launcher resume می‌کنه
3. اگه بازم ناموفق، Server admin رو آگاه کن

### مشکل: "Storage full (23 GB used)"

**دلیل:** Cache پُره

**راهنمایی:**
1. Storage → دکمه **Refresh** رو زن
2. نسخه‌های قدیمی حذف کن (45+ روز بدون استفاده)
3. مود‌های بلااستفاده حذف کن (60+ روز)

### مشکل: "Game won't launch"

**دلیل:** Mods incompatible یا game path غلط

**راهنمایی:**
1. Settings → Game Path رو چک کن (باید `ProjectZomboid.exe` داشته باشه)
2. بازی رو دستی اجرا کن تا ببینی کار می‌کنه
3. اگه بازی خود خراب شده:
   - Storage → v42.X حذف کن
   - دوباره Join کن

## نکات اضافی

### اتصال آفلاین

اگه اینترنت قطع شه:
- نسخه‌های دانلود‌شده کار می‌کنن ✅
- نسخه‌های جدید دانلود نمی‌شن ❌

### Mods متارز

بیشتر مود‌های Workshop Steam با هم کار می‌کنند.

اگه conflict باشه:
- Server admin باید mod list رو ورژن‌بندی کنه
- یا تو مود رو غیرفعال کنی

### اقتصاد فضا

ایستیوری تقریبی برای ۵ سرور:
- نسخه‌های بازی: ۶.4 GB (اشتراک)
- مود‌های مشترک: ۴ GB (اشتراک)
- **کل**: ۱۰-۱۲ GB (نه ۱۶۰ GB!)
